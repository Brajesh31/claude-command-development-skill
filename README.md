# Command Development for Claude Code

A practical guide for creating, organizing, testing, and maintaining Claude Code slash commands.

## Topics

- Command Markdown files and YAML frontmatter.
- Project, user, and plugin command locations.
- Arguments, positional parameters, and file references.
- Shell context and safe input handling.
- Tool permissions and command organization.
- Testing, troubleshooting, and documentation patterns.

## Included resources

This repository includes example commands and detailed references covering advanced workflows, frontmatter, interactive commands, plugin features, testing strategies, and documentation patterns.

## Usage

Use when designing slash commands or troubleshooting command behavior. Consult the relevant files in `examples/` and `references/`. Confirm feature support against the installed Claude Code version.
